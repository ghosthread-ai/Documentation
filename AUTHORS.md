I built Ghosthread because every automation tool for Windows was
asking the same thing from me: *stop what you're doing and watch.*
I wanted something that worked the way a second pair of hands would —
quietly, off-screen, without stealing my cursor or interrupting what
I was typing. Nothing existed that did that. So I made it.

If you found this project and want to reach out — feedback, bug
reports, questions, or just to say hi — please do. I read every
message.
