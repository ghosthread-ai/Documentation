# Code of Conduct

## The short version

Be kind. Be honest. Assume good faith. If you wouldn't say it to
someone's face, don't post it here.

---

## Our commitment

Ghosthread AI is a solo project. The discussion spaces around it —
GitHub issues, emails, social media — are meant to be places where
people can report problems, suggest ideas, and ask questions without
being attacked, dismissed, or talked down to.

That applies regardless of someone's experience level, technical
background, nationality, language, gender, identity, age, or anything
else that has nothing to do with the quality of what they're saying.

## What is expected

- **Treat others with respect.** Disagreement is fine. Contempt is not.
- **Give constructive feedback.** If you're reporting a problem, say
  what you'd like to see instead.
- **Be patient.** This is a solo, part-time project run by a student.
  Response times vary. A delayed reply is not an insult.
- **Assume good faith.** If a comment reads harshly, consider that it
  may be a language barrier, a bad day, or simple brevity, and not an
  attack.
- **Keep it relevant.** Issues are for Ghosthread. Not for unrelated
  politics, feuds, or off-topic arguments.

## What is not tolerated

- Harassment, insults, threats, or personal attacks.
- Discriminatory language or imagery.
- Sexualized language or unwanted sexual attention.
- Deliberate misinformation about the project or its author.
- Doxxing — publishing someone's private information without consent.
- Sustained disruption of discussions.
- Attempts to pressure, bribe, or manipulate the project's direction
  through any means other than honest feedback.

## Reporting a concern

If you experience or witness behavior that breaks this Code of Conduct,
email **ghosthreadai@gmail.com**. Reports are treated seriously and
confidentially.

If the concern involves the project's author, we'll handle it as
directly and honestly as possible — which means acknowledging it rather
than dismissing it.

## Consequences

The response to a violation depends on the severity and pattern of the
behavior. It can range from a private warning, to a temporary block
from participation, to a permanent ban from the project's spaces. The
project reserves the right to make these decisions.

## Scope

This Code of Conduct applies to any space where Ghosthread AI is being
discussed in an official capacity — the GitHub repository, official
social media channels, direct emails, and any future communication
channels the project opens. It also applies when someone is
representing the project publicly.
